# Database Schema & Entity Relations

## Overview
The persistence layer for **InterviewX AI** is built on Supabase PostgreSQL with structured schema definitions, relations, and JSONB payload support.

---

## Tables

### 1. `candidates`
Stores candidate profile records and recruitment state.
- `id` (UUID, Primary Key)
- `name` (TEXT, Not Null)
- `email` (TEXT, Not Null, Unique)
- `role` (TEXT)
- `resume_url` (TEXT)
- `skills` (TEXT[])
- `extracted_data` (JSONB)
- `status` (TEXT: `Invited`, `Reviewing`, `Completed`)
- `overall_score` (NUMERIC)
- `interview_id` (UUID, Foreign Key -> `interviews.id`)
- `created_at` (TIMESTAMPTZ)

### 2. `interviews`
Stores scheduled and active assessment configurations.
- `id` (UUID, Primary Key)
- `title` (TEXT, Not Null)
- `type` (TEXT: `async`, `live`)
- `job_role` (TEXT)
- `department` (TEXT)
- `duration` (INTEGER)
- `status` (TEXT: `Draft`, `Active`, `Completed`)
- `candidate_id` (UUID, Foreign Key -> `candidates.id`)
- `settings` (JSONB: proctoring events, recordings list, summary metrics)
- `created_at` (TIMESTAMPTZ)

### 3. `questions`
Stores technical and behavioral questions associated with interviews.
- `id` (UUID, Primary Key)
- `interview_id` (UUID, Foreign Key -> `interviews.id`)
- `text` (TEXT, Not Null)
- `category` (TEXT)
- `difficulty` (TEXT: `Easy`, `Medium`, `Hard`)
- `duration` (INTEGER)
- `question_order` (INTEGER)
- `created_at` (TIMESTAMPTZ)

### 4. `answers`
Stores submitted video/text answers and transcriptions.
- `id` (UUID, Primary Key)
- `interview_id` (UUID, Foreign Key -> `interviews.id`)
- `question_id` (UUID, Foreign Key -> `questions.id`)
- `candidate_id` (UUID, Foreign Key -> `candidates.id`)
- `answer_text` (TEXT)
- `transcript` (TEXT)
- `recording_url` (TEXT)
- `time_taken` (INTEGER)
- `status` (TEXT: `Pending`, `Processing`, `Completed`)
- `score` (NUMERIC)
- `evaluation` (JSONB)
- `created_at` (TIMESTAMPTZ)

### 5. `reports`
Stores idempotent, finalized assessment reports generated by the evaluation engine.
- `id` (UUID, Primary Key)
- `interview_id` (UUID, Unique Foreign Key -> `interviews.id`)
- `candidate_id` (UUID, Foreign Key -> `candidates.id`)
- `overall_score` (NUMERIC)
- `technical_score` (NUMERIC)
- `problem_solving_score` (NUMERIC)
- `communication_score` (NUMERIC)
- `recommendation` (TEXT: `STRONG HIRE`, `HIRE`, `HIRE WITH RESERVATIONS`, `NO HIRE`)
- `summary` (TEXT)
- `strengths` (TEXT[])
- `weaknesses` (TEXT[])
- `question_analysis` (JSONB[])
- `timeline` (JSONB[])
- `proctoring_summary` (JSONB)
- `created_at` (TIMESTAMPTZ)
- `updated_at` (TIMESTAMPTZ)

---

## Storage Buckets
- `resumes`: Candidate PDF/DOCX resume documents.
- `interview-recordings`: Encrypted WebM audio/video stream recordings.
